# Codex Pet Activity Implementation Plan

> **For agentic workers:** Implement this plan inline, one task at a time.

**Goal:** Replace the Zalo badge with a Codex-style pet that preserves the Zalo messages and link, and mirrors real AI activity in Word2LaTeX.

**Architecture:** A small shared activity store exposes Running, Needs input, Ready, and Blocked states. `authFetch` reports AI endpoint results; long-running AI Work and MarkItDown operations keep Running active across background waits or chunk gaps. The existing floating widget displays the original Codex v2 sprite sheet and keeps its Zalo contact behavior.

**Tech Stack:** React, TypeScript, existing Motion package, original Codex WebP spritesheet, existing authFetch wrapper.

**Spec:** User-approved design in the current conversation (October 3, 2026).

## Global Constraints

- Preserve the existing Zalo message strings, URL, and hide control.
- Show activity only while Word2LaTeX AI work is actually running; do not invent progress.
- Add no dependencies.
- Return to the rotating Zalo messages after a short completion or error notice.

## Review Focus

- Overlapping AI requests keep the pet Running until all active requests end.
- The AI Work 202 response remains Running until Firestore reports completion or failure.
- Authentication errors show Needs input; other failed requests show Blocked.
- The close control still hides the widget, and the pet remains a usable Zalo link on mobile.
- Pet motion respects reduced-motion preferences.
