# AI Work Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Implement reviewed AI text edits for Google Docs in Sync Hub, replacing its exam tab.
**Architecture:** Browser reads Docs with existing per-account Drive session; authenticated AI endpoint proposes structured paragraph edits. A local immutable proposal and diff precede revision-locked atomic writes; inverse edits enable guarded undo.
**Tech Stack:** React, TypeScript, existing Gemini SDK, Google Docs API, Node assert checks.
**Spec:** docs/superpowers/specs/2026-10-01-ai-work-design.md

## Global Constraints
- No writes before Proceed; Cancel leaves the original unchanged.
- Tokens stay in browser; only task and supported document text go to AI on Generate.
- Preserve standalone QBuilder, existing dirty work, and unsupported document elements.
- No new dependencies or production deployment.

## Review Focus
- Concurrent edits: reject stale revision, never overwrite collaborators.
- Model output: reject unknown/duplicate block IDs and malformed or no-op edits.
- Equations/images: exclude mixed non-text paragraphs from mutable ranges.
- Task/document changes during async work: discard stale results; disable apply.
- Timeout after write: show uncertain outcome, no blind retry or undo.
